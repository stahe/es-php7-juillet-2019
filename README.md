# Introducción a PHP 7: Scripts de consola y servicios web

📘 **Accede a la documentación del curso:** [https://stahe.github.io/es-php7-juillet-2019/](https://stahe.github.io/es-php7-juillet-2019/)

---

Este proyecto ofrece una recopilación de scripts de consola de PHP 7 que ilustran diversos aspectos del lenguaje y su ecosistema.

## Contenido del repositorio

Los ejemplos abarcan los siguientes temas:
- **Estructuras del lenguaje**
- **Acceso a archivos**
- **Acceso a bases de datos**
- **Acceso a Internet**

## Enfoque web

La programación web se aborda aquí desde la perspectiva de los **servicios web**. En este contexto, definimos un «servicio web» como cualquier aplicación que produzca texto sin formato (servidores de datos), a diferencia de los servidores de páginas web que generan una mezcla de HTML, CSS y JavaScript.

### Conceptos clave tratados
El proyecto explora conceptos web fundamentales utilizados en la programación tradicional:
- Protocolo HTTP
- Formatos de respuesta JSON o XML
- Gestión de sesiones
- Autenticación
