    5. Clases

    Vocabulario: Una clase es un tipo de PHP. Una variable de este tipo se denomina objeto. Un objeto es una instancia (instance) de una clase.

    5.2. Cualquier variable puede convertirse en un objeto con atributos

    El script [classes-01.php] es el siguiente:

    
<?php
 
// a generic object
// $obj1=new stdClass();
// any variable can have attributes by construction
$obj1->attr1 = "un";
$obj1->attr2 = 100;
// displays the
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
// modify object
$obj1->attr2 += 100;
// displays the
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
// copies the value of object1 (address of the object pointed to) to object2
// the two variables are then different but point to the same object
$obj2 = $obj1;
// modify obj2
$obj2->attr2 = 0;
// displays both objects
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
print "objet2=[$obj2->attr1,$obj2->attr2]\n";
// changes the object pointed to by obj1
$obj1 = new stdClass();
print "obj1 :\n";
print_r($obj1);
print "obj2 :\n";
print_r($obj2);
// assigns the reference (address) from object2 to object3
// $obj2 and $obj3 are then one and the same variable
$obj3 = &$obj2;
print "obj2 :\n";
print_r($obj2);
print "obj3 :\n";
print_r($obj3);
// modify obj3
$obj3->attr2 = 10;
// displays both objects
print "objet2=[$obj2->attr1,$obj2->attr2]\n";
print "objet3=[$obj3->attr1,$obj3->attr2]\n";
// changes the object pointed to by obj2
$obj2 = new stdClass();
$obj2->attr3 = "deux";
$obj2->attr4 = 20;
// displays the two objects $obj2 and $obj3
print "obj2 :\n";
print_r($obj2);
print "obj3 :\n";
print_r($obj3);
 
// is an object a dictionary?
print count($obj3) . "\n";
while (list($attribut, $valeur) = each($obj3)) {
  print "obj3[$attribut]=$valeur\n";
}
// end
exit;

    • líneas 23–27: pretenden mostrar que $obj1 y $obj2 son dos variables diferentes: no se encuentran en la misma dirección de memoria:

    • líneas 52–54: muestran que un objeto se puede recorrer como un diccionario. Las claves del diccionario son los nombres de los atributos, y los valores del diccionario son los valores de esos mismos atributos;
    • línea 51: la función count se puede aplicar a un objeto (con una advertencia), pero no devuelve, como cabría esperar, el número de atributos. Por lo tanto, un objeto comparte similitudes con un diccionario, pero no es uno;

    5.3. Una clase Person sin atributos declarados

    El script [classes-02.php] es el siguiente:

    
<?php
 
class Personne {
 
  // class attributes
  // undeclared - can be created dynamically
  // method
  function identite() {
    // a priori, uses non-existent attributes
    return "[$this->prenom,$this->nom,$this->age]";
  }
 
}
 
// test
// attributes are public and can be created dynamically
$p = new Personne();
$p->prenom = "Paul";
$p->nom = "Langevin";
$p->age = 48;
// method call
print "personne=" . $p->identite() . "\n";
// end
exit;

    Resultados:

    1
    personne=[Paul,Langevin,48]

    Comentarios

    • líneas 3-13: definen una clase `Person`. Una clase es una plantilla que se utiliza para crear objetos. Contiene atributos y funciones denominadas «métodos». No es necesario declarar los atributos;
    • líneas 8–11: el método identity muestra los valores de tres atributos no declarados en la clase. La palabra clave $this hace referencia al objeto al que se aplica el método;
    • línea 17: creamos un objeto $p de tipo Person. La palabra clave new se utiliza para crear un nuevo objeto. La operación devuelve una referencia al objeto creado (es decir, una dirección). Son posibles varias notaciones: new Person(), new Person, new person. El nombre de la clase no distingue entre mayúsculas y minúsculas;
    • líneas 18-20: los tres atributos requeridos por el método identity se crean en el objeto $p;
    • línea 22: se aplica el método identity de la clase Person al objeto $p. En el código (líneas 8-11) del método identity, $this hace referencia al mismo objeto que $p;

    5.5. La clase Person con un constructor

    Los ejemplos anteriores mostraban clases Person poco habituales, tal y como se podían encontrar en PHP 4. No se recomienda seguir estos ejemplos. A continuación, presentamos una clase Person [classes-04.php] que sigue las mejores prácticas de PHP 7:

    
<?php
 
// strict adherence to declared types of function parameters
declare (strict_types=1);
class Personne {
// class attributes
  private $prenom;
  private $nom;
  private $age;
 
// getters and setters
  public function getPrenom(): string {
    return $this->prenom;
  }
 
  public function getNom(): string {
    return $this->nom;
  }
 
  public function getAge(): int {
    return $this->age;
  }
 
  public function setPrenom(string $prenom): void {
    $this->prenom = $prenom;
  }
 
  public function setNom(string $nom): void {
    $this->nom = $nom;
  }
 
  public function setAge(int $age): void {
    $this->age = $age;
  }
 
// manufacturer
  public function __construct(string $prenom, string $nom, int $age) {
    // we go through sets
    $this->setPrenom($prenom);
    $this->setNom($nom);
    $this->setAge($age);
  }
 
// method toString
  public function __toString(): string {
    return "[$this->prenom,$this->nom,$this->age]";
  }
 
}
 
// test
// creation of a Personne object
$p = new Personne("Paul", "Langevin", 48);
// identity of this person
print "personne=$p\n";
// we change the age
$p->setAge(14);
// identity of the person
print "personne=$p\n";
// end
exit;

    • líneas 7-9: los atributos privados de la clase. Estos atributos solo son visibles dentro de la clase. Otras palabras clave que se pueden utilizar son:
    • public: convierte el atributo en un atributo público visible desde fuera de la clase,
    • protected: convierte el atributo en un atributo protegido, visible desde dentro de la clase y sus clases derivadas;
    • dado que los atributos son privados, no se puede acceder a ellos desde fuera de la clase. Por lo tanto, no podemos escribir el siguiente código:

    • utilizar el constructor de las líneas 37–42. Entonces escribiríamos: 
    1
    $p=new Personne("Michel","Landru",44) ;

    • Todos los métodos de la clase (funciones) llevan el prefijo de la palabra clave public, lo que indica que la función es visible desde fuera de la clase. Las otras palabras clave que se pueden utilizar son, al igual que con los atributos y con el mismo significado, private y protected. Sin un atributo de visibilidad explícito, la función tiene visibilidad pública implícita;

    5.6. La clase Person con comprobaciones de validez en el constructor

    El constructor de una clase es el lugar adecuado para verificar que los valores de inicialización del objeto sean correctos. Sin embargo, un objeto también puede inicializarse mediante sus métodos de configuración o equivalentes. Para evitar duplicar las mismas comprobaciones en dos lugares distintos, estas comprobaciones pueden incluirse dentro de los métodos de configuración. Si se detecta que el valor de inicialización de un objeto es incorrecto, se lanza una excepción. A continuación se muestra un ejemplo.

    En primer lugar, trasladamos la definición de la clase Person a su propio archivo [Person.php]:

    
<?php
 
// strict adherence to declared types of function parameters
declare (strict_types=1);
 
// namespace;
namespace Exemples;
 
// person class
class Personne {
// class attributes
  private $prenom;
  private $nom;
  private $age;
 
// getters and setters
  public function getPrenom(): string {
    return $this->prenom;
  }
 
  public function getNom(): string {
    return $this->nom;
  }
 
  public function getAge(): int {
    return $this->age;
  }
 
  public function setPrenom(string $prénom): void {
    // first name must be non-empty
    $prénom = trim($prénom);
    if ($prénom === "") {
      throw new \Exception("Le prénom doit être non vide");
    } else {
      $this->prenom = $prénom;
    }
  }
 
  public function setNom(string $nom): void {
    // name must be non-empty
    $nom = trim($nom);
    if ($nom === "") {
      throw new \Exception("Le nom doit être non vide");
    } else {
      $this->nom = $nom;
    }
  }
 
  public function setAge(int $âge): void {
    // age must be valid
    if ($âge < 0) {
      throw new \Exception("L'âge doit être un entier positif ou nul");
    } else {
      $this->age = $âge;
    }
  }
 
// manufacturer
  public function __construct(string $prenom, string $nom, int $age) {
    // we go through sets
    $this->setPrenom($prenom);
    $this->setNom($nom);
    $this->setAge($age);
  }
 
  // method
  public function initWithPersonne(Personne $p): void {
    // initializes the current object with a person $p
    $this->__construct($p->prenom, $p->nom, $p->age);
  }
 
  // method toString
  function __toString(): string {
    return "[$this->prenom,$this->nom,$this->age]";
  }
 
}

    Comentarios

    • línea 4: especifica que se debe respetar el tipo de los parámetros de la función al declararlos;
    • línea 7: define un espacio de nombres. El nombre completo (o calificado) de la clase Person es, por tanto, \Examples\Person. Fíjate en el carácter \ al principio del nombre calificado: esto da como resultado un nombre calificado absoluto. Si este carácter no aparece, el nombre es relativo (en relación con el espacio de nombres actual). Por lo tanto, si dos clases A y B forman parte del mismo espacio de nombres E, en el código de la clase A se puede acceder a la clase B utilizando la notación relativa B. Si la clase A forma parte del espacio de nombres E1 y B forma parte del espacio de nombres E2, en el código de A se accederá a B utilizando la notación absoluta \E2\B. Definir una clase dentro de un espacio de nombres no es obligatorio, pero NetBeans emite una advertencia si no lo haces. Por lo tanto, lo haremos. Además, los espacios de nombres deben corresponder a la estructura del directorio de archivos. Así, la clase A en el espacio de nombres E1 debe estar en un archivo llamado E1/A.php. Esto no es obligatorio, pero, de nuevo, NetBeans emite una advertencia si no lo haces. En el ejemplo de la clase [\Exemples\Personne], NetBeans emite una advertencia porque la ruta del archivo [Personne.php] es [exemples/classes/Personne.php] y, por lo tanto, no coincide con el espacio de nombres. No confunda la ruta del archivo con el espacio de nombres. El nombre completo de una clase utiliza un espacio de nombres y no tiene nada que ver con la ruta del archivo PHP de la clase. La relación entre la ruta del archivo y el espacio de nombres es opcional y puede ignorarse, como hemos hecho aquí;
    • líneas 12-14: los tres atributos privados de la clase;
    • líneas 29–37: inicialización del atributo first_name y verificación del valor de inicialización;
    • línea 31: la función trim($string) elimina los espacios al principio y al final de $string. Por lo tanto, trim("abcd") es la cadena "abcd" y trim(" ") es la cadena vacía;
    • línea 32: si el nombre es vacío, se lanza una excepción (línea 33); de lo contrario, se almacena el nombre (línea 35). Para lanzar una excepción, hemos utilizado aquí la clase predefinida [Exception]. Aquí se nos exige utilizar su nombre absoluto [\Exception]. Si utilizamos su nombre relativo [Exception], entonces esta clase se buscará en el espacio de nombres actual, es decir, el espacio de nombres [Examples] de la clase Person. Por lo tanto, el intérprete de PHP buscará una clase con el nombre absoluto [\Examples\Exception], que no existe;

    • línea 7: el script utilizará la clase [Person]. Por lo tanto, debemos indicar al intérprete de PHP dónde puede encontrar la definición de esta clase. Esta es la función de las sentencias [include file] y [require file]. Aquí hemos utilizado la sentencia [include]. La diferencia entre ambas sentencias es la siguiente: si la sentencia [include file] encuentra errores al cargar [file], se emite un error [E_WARNING] pero la ejecución continúa, mientras que [require], en el mismo caso, genera un error fatal y la ejecución del script se detiene. Cada una de estas dos sentencias tiene una variante: [include_once] y [require_once]. Estas dos variantes permiten gestionar los casos en los que se incluye el mismo archivo varias veces. Consideremos un proyecto compuesto por varios scripts PHP, algunos de los cuales hacen referencia a la clase [Person]. Su ejecución provocará que el archivo [Person.php] se incluya varias veces, lo que dará lugar a un error, ya que una clase no se puede definir dos veces. La solución es utilizar las variantes [_once], que garantizan que el archivo solo se incluya una vez en el script global del proyecto;
    • línea 7: la constante [__DIR__] es una constante de PHP que hace referencia a la ruta completa del directorio que contiene el script con la constante [__DIR__]. Por lo tanto, la expresión de la línea 17: 
    
require_once __DIR__."/Personne.php";

    será equivalente a algo como:

    
require_once ‘C:\Data\st-2019\dev\php7\php5-exemples\exemples\classes/Personnes.php’

    En la ruta del archivo, puedes usar tanto / como \;

    • Línea 14: Utilizamos la clase [Person] que acabamos de definir. El script [classes-05.php] no tiene espacios de nombres. La línea 14 utiliza el nombre relativo de la clase [Person] sin espacio de nombres. Dado que la clase [Person] no tiene espacio de nombres, se busca dentro del propio script [classes-05.php] y, por lo tanto, no se encuentra. Hay dos soluciones para este problema:

      • utilizar la instrucción `use` en la línea 10. Esto indica que el código que sigue utiliza la clase `[Examples\Person]`;

Dicho esto, ¿dónde encontrará el intérprete el código de esta clase? La línea 7 se lo indica. Esta línea indica que, para ejecutar el script actual, también debe cargarse el script [Person.php]. Aquí se utiliza el nombre de archivo relativo. Por lo tanto, se buscará en la carpeta que contiene el script [classes-05.php]. Los scripts [Person.php] y [classes-05.php] deben estar, por lo tanto, en la misma carpeta. Este es el caso aquí, donde ambos se encuentran en la carpeta [examples/classes]. function __construct(string $prenom, string $nom, int $age)

    5.14. Clases abstractas

    Una clase abstracta es una clase incompleta que no se puede instanciar. Para poder utilizarla, es necesario derivarla.

    ¿Para qué se utiliza una clase abstracta? A veces tenemos clases que comparten uno o más métodos, pero difieren en otros métodos o atributos. En ese caso, es conveniente agrupar todo lo que es común en una clase padre. Por ahora, no necesitamos una clase abstracta. Pero supongamos que las clases hijas solo difieren en un método, M: la firma del método sería la misma en todas las clases hijas, pero su implementación sería diferente. Para exigir que las clases hijas implementen el método M:

    • Declararemos la firma del método M en la clase padre. Dado que la clase padre no sabe cómo implementarlo, anteponemos al método la palabra clave «abstract»: esto significa que la implementación del método M se deja en manos de las clases hijas;
    • dado que la clase padre no está completamente implementada, también se declara abstracta utilizando la misma palabra clave abstract. Esto significa que la clase ya no se puede instanciar. Se debe crear una clase hija para definir la implementación del método M, de modo que se pueda utilizar el cuerpo de la clase padre;

    Aquí hay un ejemplo [classes-15.php]:

    
<?php
 
// strict adherence to function parameter types

// abstract main class
abstract Class Classe1 {
 
  // method known to all derived classes
  public function f(): int {
    return 1;
  }
 
  // abstract g method - will be defined by derived classes
  abstract function g(): int;
}
 
// derived class
Class Classe2 extends Classe1 {
 
  // the g method of the parent class must be defined
  public function g(): int {
    return parent::f() + 10;
  }

}
 
// derived class
Class Classe3 extends Classe1 {
 
  // the g method of the parent class must be defined
  public function g(): int {
    return parent::f() + 20;
  }
 
  // we can redefine the f method of the parent class
  public function f(): int {
    return 2;
  }
 
}
 
// code
$c2 = new Classe2();
print $c2->f() . "\n";
print $c2->g() . "\n";
$c3 = new Classe3();
print $c3->f() . "\n";
print $c3->g() . "\n";

    5.19. Codificación JSON de una clase

    En una clase, suele estar presente el método [__toString]: se supone que debe devolver una cadena que represente al objeto que lo invoca. Puede resultar tentador que esta cadena sea una cadena JSON. Exploraremos esta vía ahora.

    Utilizaremos la siguiente clase [Person]:

    
<?php
 
class Personne {
  // attributes
  private $nom;
  private $prénom;
  private $âge;
  private $enfants;
 
  // setter global
  public function setFromArray(array $arrayOfAttributes): Personne {
    // initialization of certain class attributes
    foreach ($arrayOfAttributes as $attribute => $value) {
      $this->$attribute = $value;
    }
    // object is returned
    return $this;
  }
 
  // getters
  public function getNom() {
    return $this->nom;
  }
 
  public function getPrénom() {
    return $this->prénom;
  }
 
  public function getÂge() {
    return $this->âge;
  }
 
  public function getEnfants() {
    return $this->enfants;
  }
 
  // __toString
  public function __toString(): string {
    // we identify the object
    var_dump($this);
    // retrieve its attributes
    $attributes = \get_object_vars($this);
    var_dump($attributes);
    // render the jSON attribute string
    return \json_encode($attributes, JSON_UNESCAPED_UNICODE);
  }
 
}

class Personne3 {
  // attributes
  private $nom;
  private $prénom;
  private $âge;
  private $enfants;
 
  // setter global
  public function setFromArray(array $arrayOfAttributes): Personne3 {
    …

  // getters
  …
 
  // __toString
  public function __toString(): string {
    // render the JSON attribute string
    $attributes = [];
    $this->getRecursiveAttributes($attributes, $this, []);
    // string JSON of attributes
    return \json_encode($attributes, JSON_UNESCAPED_UNICODE);
  }
 
  public function getAttributes(): array {
    return \get_object_vars($this);
  }
 
  private function getRecursiveAttributes(array &$attributes, $value, $keys): void {
    // value analysis [$value]
    // $keys is an array [key1, key2, .., keyn]
    // $value=$attributes[key1][key2]….[keyn]
    // if [$value] is an object, we use its method [getAttributes]
    if (\is_object($value)) {
      // attributs de l'objet [$value]
      $objectAttributes = $value->getAttributes();
      // what do we do with the result?
      if ($keys) {
        // in [$attributes], we replace $value with the array of its attributes
        // element $attributes[key1][key2]...[keyn] must be constructed
        // where $keys is the array [key1, key2, .., keyn]
        // we take the table reference [$attributes]
        $attribute = &$attributes;
        // scan the key table
        foreach ($keys as $key) {
          // we take the reference of the
          $attribute = &$attribute[$key];
        }
        // here $attribut and $attributes[key1][key2]...[key(n)] are identical
        // they share the same memory location
        // object [$value] is replaced by its array of attributes;
        // write $attributes[key1][key2]...[keyn]=$objectAttributes
        // which is equivalent to $attribute = $objectAttributes
        $attribute = $objectAttributes;
      } else {
        // no keys - we're just beginning to explore the object
        // $objectAttributes represents the 1st level attributes of the class
        $attributes += $objectAttributes;
      }
      // maybe in [$objectAttributes] there are still objects
      // explore [$objectAttributes] attributes
      $this->getRecursiveAttributes($attributes, $objectAttributes, $keys);
    } else {
      if (\is_array($value)) {
        // we have a table - we analyze each of its elements
        foreach ($value as $key => $élément) {
          // add the current key to the $keys array
          \array_push($keys, $key);
          // we analyze $élément
          $this->getRecursiveAttributes($attributes, $élément, $keys);
          // remove the key just analyzed from the $keys array
          \array_pop($keys);
        }
      }
    }
  }

    Comentarios

    • líneas 21–22: en esta ocasión, el método [__toString] recupera los atributos de su clase y solicita que esto se haga de forma recursiva: si un atributo es un objeto o una matriz de objetos, entonces cada objeto debe ser sustituido por su matriz de atributos en la matriz final de atributos de la clase;
