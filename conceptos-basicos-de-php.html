    A continuación se muestra un programa [bases-01.php] que muestra las características básicas de PHP.

    
<?php
 
// this is a comment
// variable used without being declared
$nom = "dupont";
// a screen display
print "nom=$nom\n";
// an array with elements of different types
$tableau = array("un", "deux", 3, 4);
// its number of elements
$n = count($tableau);
// a loop
for ($i = 0; $i < $n; $i++) {
  print "tableau[$i]=$tableau[$i]\n";
}
// initialize 2 variables with the contents of an array
list($chaine1, $chaine2) = array("chaine1", "chaine2");
// concatenation of the 2 strings
$chaine3 = $chaine1 . $chaine2;
// result display

// use function

  print "t[$i]=$t[$i]\n";

  if (getType($t[$i]) === "string") {
    print "t[$i]=$t[$i]\n";
  }
}

    Comentarios

    • línea 5: En PHP, no se declaran los tipos de variables. Las variables tienen un tipo dinámico que puede cambiar con el tiempo. $name representa la variable con el identificador name;
    • línea 7: para mostrar el resultado en pantalla, puedes utilizar la instrucción print o la instrucción echo;
    • línea 9: la palabra clave array se utiliza para definir una matriz. La variable $name[$i] representa el elemento $i-ésimo de la matriz $array;
    • línea 11: la función count($tableau) devuelve el número de elementos del array $tableau;
    • líneas 13–15: un bucle. Dado que este bucle contiene solo una instrucción, las llaves son opcionales. En el resto de este documento, siempre utilizaremos llaves independientemente del número de instrucciones;
    • línea 14: las cadenas se escriben entre comillas dobles " o comillas simples '. Dentro de las comillas dobles, las variables $variable se evalúan, pero no dentro de las comillas simples;
    • línea 17: la función list permite agrupar variables en una lista y asignarles un valor con una sola operación de asignación. Aquí, $chaine1="chaine1" y $chaine2="chaine2";
    • línea 19: el operador . es el operador de concatenación de cadenas;
    • líneas 83–86: la palabra clave `function` define una función. Una función puede devolver valores o no mediante la instrucción `return`. El código que la invoca puede ignorar o recuperar los resultados de una función. Una función se puede definir en cualquier parte del código.
    • línea 92: la función predefinida getType($variable) devuelve una cadena que representa el tipo de $variable. Este tipo puede cambiar con el tiempo;
    • Línea 45: El operador === realiza una comparación estricta de dos elementos: deben ser del mismo tipo para poder compararse. El operador == es menos estricto: dos elementos pueden ser iguales sin ser del mismo tipo. Esto se demuestra con las sentencias de las líneas 50–60. En el caso del operador ==, la comparación se realiza tras convertir ambos elementos que se comparan al mismo tipo. Entonces tienen lugar conversiones implícitas. Es bastante fácil «olvidarse» de estas conversiones implícitas y, por lo tanto, acabar con resultados inesperados, como descubrir que una condición es verdadera cuando esperabas que fuera falsa. Para evitar este escollo, utilizaremos sistemáticamente el operador de comparación ===;
    • línea 64: también puedes utilizar los operadores booleanos or e !;
    • línea 69: en lugar de la notación array(), puedes utilizar la notación [] para inicializar una matriz en PHP 7;
    • línea 80: la función predefinida exit detiene la ejecución del script;
    • línea 107: la etiqueta ?> marca el final del script PHP. No es imprescindible. Además, en un contexto web, puede causar problemas si va seguida de espacios o saltos de línea, que son difíciles de detectar porque no son visibles en un editor de texto. Por lo tanto, en el resto de este documento, omitiremos sistemáticamente esta etiqueta;

    Nota: En este documento, utilizaremos la palabra clave [print] para mostrar texto en la consola. Otra forma de hacer lo mismo es utilizar la palabra clave [echo]. Existen diferencias sutiles entre estas dos palabras clave, pero en el contexto de este documento, no habrá ninguna. Así que, si prefieres utilizar [echo], hazlo.

    3.5. Cambios de tipo

    Las variables en PHP no tienen un tipo fijo. Su tipo puede cambiar durante la ejecución dependiendo del valor asignado a la variable. En operaciones que involucran datos de varios tipos, el intérprete de PHP realiza conversiones implícitas para convertir los operandos a un tipo común. Estas conversiones implícitas, si el desarrollador no las conoce, pueden ser una fuente de errores difíciles de detectar. A continuación se muestra un script [bases-04.php] que muestra conversiones implícitas y explícitas:

    
<?php
 
// strict types for passing parameters
declare(strict_types=1);
 
// implicit type changes
// type -->bool
print "Conversion vers un booléen------------------------------\n";
showBool("abcd", "abcd");
showBool("", "");
showBool("[1, 2, 3]", [1, 2, 3]);
showBool("[]", []);
showBool("NULL", NULL);
showBool("0.0", 0.0);
showBool("0", 0);
showBool("4.6", 4.6);
 
function showBool(string $prefixe, $var) : void {
  print "(bool) $prefixe : ";
  // conversion of $var to Boolean is automatic in the following test
  if ($var) {
    print "true";
  } else {
    print "false";
  }
  print "\n";
}

    Comentarios

    • línea 4: requiere una comprobación estricta de los tipos de los parámetros de una función cuando se especifica;
    • línea 18: la función [showBool] tiene por objeto demostrar la conversión implícita (automática) que realiza el intérprete de PHP cuando un valor de cualquier tipo debe convertirse a un valor booleano (línea 21);
    • línea 18: el parámetro $var no tiene ningún tipo asignado. Por lo tanto, el parámetro real puede ser de cualquier tipo. El parámetro $prefix, por otro lado, debe ser de tipo cadena. La función showBool no devuelve ningún valor (void);
    • línea 21: en la instrucción if($var), el valor de $var debe convertirse a un valor booleano para que se evalúe el if. Sorprendentemente, el intérprete de PHP tiene una solución para cualquier tipo de valor que se le proporcione;
    • líneas 9–16: el valor del parámetro de la función [showBool] será, a su vez:
      • línea 9: una cadena no vacía: resultado TRUE (las mayúsculas y minúsculas no importan, TRUE = true);
      • línea 10: una cadena vacía: resultado FALSE;
      • línea 11: un array no vacío: resultado TRUE;
      • línea 12: una matriz vacía: resultado FALSE;
      • línea 14: el número real 0: resultado FALSE;
      • línea 15: el entero 0: resultado FALSO;
      • línea 16: un número real (o entero) distinto de 0: resultado TRUE;

    Consideremos el primer ejemplo. El patrón se define en la línea 10: denota una secuencia de uno o más (+) dígitos (\d) situados en cualquier lugar de una cadena. Además, el patrón define un subpatrón entre paréntesis;

    Explicaremos los patrones utilizados en el resto del código:

Por lo tanto, el patrón /^(.*)(\d+)(.*)$/ nunca se encontrará porque el primer subpatrón (.*) consumirá toda la cadena. El patrón (.*?)(\d+) denota 0 o más caracteres arbitrarios hasta el siguiente subpatrón (?), en este caso \d+. Por lo tanto, los dígitos ya no son capturados por el patrón (.*). El patrón anterior coincide así con [inicio de la cadena (^), una secuencia de cualquier carácter (.*?), una secuencia de uno o más dígitos (\d+), una secuencia de cualquier carácter (.*?), fin de la cadena ($)].

    corresponde a [inicio de cadena (^), 2 dígitos (\d\d), el carácter / (\/), 2 dígitos, /, 2 dígitos, una secuencia de 0 o más espacios (\s*), fin de cadena ($)].

    
$modèle = "/^\s*([+|-]?)\s*(\d+\.\d*|\.\d+|\d+)\s*/";

    coincide con el inicio de la cadena (^), 0 o más espacios (\s*), un signo + o - [+|-] que aparece 0 o 1 vez (?), una secuencia de 0 o más espacios (\s*), 1 o más dígitos seguidos de un punto decimal seguido de cero o más dígitos (\d+\.\d*) o (|) un punto decimal (\.) seguido de uno o más dígitos (\d+) o (|) uno o más dígitos (\d+), una secuencia de 0 o más espacios (\s*)].

    Nota: El término [espacio] en las expresiones regulares se refiere a un conjunto de caracteres: espacio en blanco, salto de línea \n, tabulación \t, retorno de carro \r, avance de página \f…
